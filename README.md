# Personal Portfolio Website

A simple, responsive personal portfolio website built with only HTML and CSS.

## Features

- Responsive design that works on desktop and mobile devices
- Clean, modern layout with sections for About, Skills, Projects, and Contact
- Fixed navigation header
- Hover effects and smooth transitions

## Usage

1. Open `index.html` in your web browser to view the portfolio.
2. Customize the content in `index.html` to match your personal information:
   - Replace `[Your Name]` with your actual name
   - Update the hero section description
   - Modify the About section text
   - Add or remove skills in the Skills section
   - Update project descriptions and links
   - Change contact information
3. Adjust colors, fonts, and layout in `styles.css` to match your preferences.

## Customization

- **Colors**: Change the color scheme by modifying the CSS variables or color values in `styles.css`
- **Fonts**: Update the `font-family` in the body selector
- **Layout**: Modify grid layouts or flexbox arrangements for different section structures
- **Content**: Add more sections or rearrange existing ones as needed

## Browser Support

This website works in all modern browsers that support CSS Grid and Flexbox.
